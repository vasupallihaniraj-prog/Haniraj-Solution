​Overview
​Nova Trust is a comprehensive reliability and operational intelligence layer built for Nova Cart. It bridges availability confidence, store fulfillment, and operational tracking to ensure that what is promised to customers is successfully delivered.
​Project Structure
​This submission contains the complete codebase divided into three required sections:
​frontend/: Contains the React + Vite user interface, Tailwind CSS styling, components, and pages.
​backend/: Contains the database schemas, Supabase configurations, and serverless edge functions.
​README.md: Project documentation and submission details.
​Features & Modules
​Customer Experience: End-to-end transparency layer for buyers.
​Command Center: Real-time operational intelligence dashboard.
​Impact Simulator: Simulates supply chain changes and reliability outcomes.
​Operations & Evidence: Tracking verification metrics and fulfillment logs.
